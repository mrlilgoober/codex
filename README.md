# Banjo-Kazooie Tribute: Jiggy Dash

A tiny browser fan-game prototype inspired by the Banjo-Kazooie style of collecting notes and grabbing a Jiggy.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## How to play

- Move with **Arrow keys** or **WASD**.
- Collect music notes.
- After 8 notes, a Jiggy appears.
- Grab the Jiggy to level up.
- Survive through level 3 to win.
